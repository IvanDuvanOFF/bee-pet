# 🐝 bee-pet

Пчела-питомец для рабочего стола: живёт поверх окон, у неё есть настроение, с ней можно
поболтать, а если очень разозлить — может закрыть окно Блокнота или Калькулятора.

## Запуск на Windows 10 / 11

1. Установить **Python 3.11+** с [python.org](https://www.python.org/downloads/).
   В установщике поставить галочку **«Add python.exe to PATH»**.
2. Скопировать папку проекта на Windows (без `.venv` — её нужно создать заново).
   С дуалбутом проще всего через флешку или облако; можно и одним файлом:
   `git bundle create bee-pet.bundle --all` в Linux, затем в Windows
   `git clone bee-pet.bundle bee-pet`.
3. Открыть **PowerShell** в папке проекта и выполнить один раз:
   ```powershell
   py -3 -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
4. Запустить пчелу:
   ```powershell
   .venv\Scripts\python -m bee_pet
   ```
   Чтобы не висело окно консоли, можно запускать через `pythonw`:
   ```powershell
   .venv\Scripts\pythonw -m bee_pet
   ```
   (но тогда не будет видно ошибок — для первого теста лучше обычный `python`).

Если PowerShell ругается на политику выполнения скриптов — это не про нас: команды выше
вызывают `python.exe` напрямую, активировать venv не нужно.

## Запуск на Linux (Fedora)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m bee_pet
```

На KDE Wayland пчела запустится, но перетаскивание окна и «поверх всех» работают
ограниченно, а закрытие окон отключено (только Windows). Полноценная поддержка KDE — позже.

## Как пользоваться

- **Перетащить** — зажать левую кнопку на пчеле и тащить.
- **Правый клик** — меню: дать цветок, погладить, шлёпнуть, извиниться, побрызгать,
  чат, «Разрешить кусать окна», выход.
- **Выход** — правый клик → «❌ Выход».

### Злая пчела

Если шлёпнуть пчелу, а потом сразу задабривать цветком или «i love you», она приходит
в ярость, подлетает к окну Блокнота, Калькулятора или Проводника и через 5 секунд
закрывает его (как нажатием на крестик — несохранённый текст Блокнот спросит сохранить).
Чтобы отменить, во время отсчёта нажмите «🙏 Извиниться». Отключить совсем — снять
галочку «🦷 Разрешить кусать окна» в меню.

## Чат с BeeLLM (необязательно)

Без модели пчела отвечает заготовками «бзз». При запуске она ищет модель так:

1. задана переменная `BEE_URL` — говорит через этот сервер;
2. на `http://127.0.0.1:8081` уже работает llama-server (свой или `docker compose up -d`) — через него;
3. в папке `vendor/` лежат llama-server и модель (их качает `python tools\fetch_vendor.py`,
   см. «Сборка exe») — сама запускает встроенный сервер на свободном порту и гасит его при выходе;
4. иначе — заготовки.

Чтобы отвечала настоящая BeeLLM без `vendor/`, установите
[llama.cpp](https://github.com/ggml-org/llama.cpp/releases) и запустите в отдельном окне:

```
llama-server -hf schizophyllume/BeeLLM -c 4096 --port 8081
```

Другой адрес сервера задаётся переменной окружения `BEE_URL`
(по умолчанию `http://127.0.0.1:8081`), например в PowerShell:
`$env:BEE_URL="http://127.0.0.1:9000"`.

## Сборка exe из исходников

Получается один файл `bee-pet.exe`: Python для запуска не нужен,
модель BeeLLM и llama-server уже внутри, чат и настроение от модели работают сразу.
Команды для **PowerShell** в папке проекта (нужны Python 3.11+ и интернет).

> Положите проект в папку с коротким путём, например `C:\bee-pet`. Внутри PySide6 есть
> файлы с очень длинными именами, и в глубоко вложенной папке `pip install` падает
> с ошибкой `[WinError 206] The filename or extension is too long` (ограничение Windows
> на 260 символов в пути; его можно снять в настройках «Включить длинные пути Win32»).

1. Окружение (если `.venv` уже есть, первую команду можно пропустить):
   ```powershell
   py -3 -m venv .venv
   ```
   ```powershell
   .venv\Scripts\pip install -r requirements-build.txt
   ```
2. Скачать llama-server (llama.cpp `b11645`, Windows x64, CPU) и модель
   `BeeLLM-12M-Mood.gguf` в `vendor/` (~70 МБ; версии и SHA256 зашиты в скрипт,
   при несовпадении хеша он остановится; повторный запуск ничего не качает):
   ```powershell
   .venv\Scripts\python tools\fetch_vendor.py
   ```
3. Собрать (1–3 минуты):
   ```powershell
   .venv\Scripts\pyinstaller --noconfirm bee-pet.spec
   ```
   Результат — **`dist\bee-pet.exe`**, около 86 МБ. Первый запуск занимает несколько
   секунд: exe распаковывается во временную папку (её проверяет антивирус).

**Вариант папкой** — стартует быстрее (~2 с) и не распаковывается при каждом запуске,
но отдавать нужно всю папку `dist\bee-pet\` (~150 МБ, запускать `bee-pet.exe` внутри):
```powershell
$env:BEE_ONEDIR="1"; .venv\Scripts\pyinstaller --noconfirm bee-pet.spec; Remove-Item Env:BEE_ONEDIR
```

Папки `vendor/`, `build/` и `dist/` в git не попадают.

### Важное

- **«Windows защитила ваш компьютер»** (SmartScreen) — exe не подписан. Нажать
  «Подробнее» → «Выполнить в любом случае».
- Антивирус может ругаться на exe из PyInstaller — это ложное срабатывание, но решать
  вам: исходники открыты, собрать можно самому.
- Пчела появляется поверх окон, значка в панели задач нет. Всё управление — **правый клик**
  по пчеле. Там же переключатели:
  - «🦷 Разрешить кусать окна» — **включено**: очень злая пчела закрывает окно Блокнота,
    Калькулятора или Проводника (с отсчётом 5 секунд, «🙏 Извиниться» отменяет);
  - «🪟 Переключать окна, пока меня нет» — **включено**: через 2 минуты без мыши
    и клавиатуры пчела выводит на передний план другое окно;
  - «🖱 Таскать ярлыки от скуки» — **выключено**.
- **Выход** — правый клик → «❌ Выход» (встроенный сервер модели закрывается вместе с пчелой).
- **Лог** — `%LOCALAPPDATA%\bee-pet\bee-pet.log` (и `llama-server.log` рядом).

## Планы на будущее

Пока не сделано, это идеи для следующих версий.

1. **Действия по ответам модели.** BeeLLM описывает действия в звёздочках:
   `*stings you*`, `*throws the flower back at you*`, `*chases you around the room*`,
   `*dive bombs you*`, `*knocks the can out of your hand*`. Пчела будет разбирать эти
   фрагменты и выполнять соответствующее действие на экране, а не только показывать
   текст в пузыре.
2. **Ужаливание курсора.** Когда модель отвечает `*stings you*`, пчела подлетает
   к курсору мыши и делает выпад жалом. На этой анимации можно проверить систему
   действий из первого пункта.
3. **Озвучка жужжания.** Пчела будет произносить свои реплики («bzz», «BZZZZZ!!»)
   звуком. Громкость и тембр зависят от настроения: спокойное жужжание тихое, злое
   громкое и резкое. Звук можно выключить в меню.

## Для разработки

```bash
.venv/bin/pip install -r requirements-dev.txt
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
```

Проверить встроенный сервер, когда на 8081 уже работает docker: `BEE_FORCE_BUNDLED=1`
заставляет пчелу игнорировать `BEE_URL` и порт 8081 и запустить llama-server из `vendor/`
(или из exe), например `$env:BEE_FORCE_BUNDLED="1"; .\dist\bee-pet.exe`.

Ручная проверка на Windows — чек-лист в [`docs/windows-test.md`](docs/windows-test.md).
