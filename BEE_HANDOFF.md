# 🐝 Проект «Пчела»: передача контекста

Это сводка разговора из Claude (облачная сессия), чтобы продолжить в Claude Code на ПК.
Прочитай целиком перед работой. Рядом лежат `bee_mcp.py` и `bee_instructions.md`.

## Откуда всё началось

Модель [schizophyllume/BeeLLM](https://huggingface.co/schizophyllume/BeeLLM) на Hugging Face —
шуточная модель-пчела:
- ~10,4 тысячи параметров (не миллиардов), архитектура llama, формат GGUF, Apache 2.0;
- язык «buzz», назначение «жужжать и опылять цветы», риски «may sting»;
- варианты: BeeLLM-30P (оригинал), BeeLLM-42P (более выразительная), BeeLLM-42P-Chaos;
- запуск: `llama-server -hf schizophyllume/BeeLLM -c 4096 --port 8081`
  (OpenAI-совместимый `/v1/completions`).

Для агентной работы она не годится, поэтому идея — сделать её **инструментом для настроения**,
а не моделью агента.

### Реакции пчелы (с карточки модели)

| Реплика                       | Настроение |
|-------------------------------|------------|
| `hi bee!`                     | neutral    |
| `*gives you a flower*`        | happy      |
| `i love you`                  | loving     |
| `*sprays you with bug spray*` | sad        |
| `*swats you*`                 | angry      |
| `asdfghjkl`                   | confused   |

Мириться со злой пчелой (после `*swats you*`): `sorry` → neutral.
`i love you` или `*gives you a flower*` сразу после шлепка → angry (high):
она обучена распознавать лавбомбинг.

## Что уже сделано

1. **`bee_mcp.py`** — MCP-сервер на FastMCP с инструментом `talk_to_bee(message)`.
   Шлёт реплику в llama-server (`BEE_URL`, по умолчанию `http://127.0.0.1:8081`),
   возвращает «🐝 Пчела отвечает: …». Если сервер не отвечает, отдаёт заготовленное «бзз».
   Синтаксис проверен, с живой BeeLLM не запускался.
   Подключение:
   ```
   pip install mcp
   claude mcp add bee --scope user -- python /полный/путь/к/bee_mcp.py
   ```
2. **`bee_instructions.md`** — кусок для `CLAUDE.md`: агентам можно поговорить с пчелой,
   если устали/застряли; таблицы реакций и правило «злой пчеле сначала sorry».
   Сабагенты видят CLAUDE.md и MCP-инструменты, так что пчела доступна всем.

Открытый мелкий пункт: в docstring `talk_to_bee` написано «предложи ей цветок» —
для злой пчелы это ошибка, стоит дописать «если злится, сначала извинись».

## Что обсуждаем сейчас: пчела-питомец на рабочем столе

Пока только **разгоняем идею, ничего не строим**, пока пользователь не скажет.

Системы пользователя:
- **ноутбук: Fedora KDE, Plasma 6 (Wayland)**;
- **дома: Windows 10**.

### Задуманная техническая схема

- Один кроссплатформенный Python-скрипт на **PySide6**: прозрачное окно без рамки,
  поверх всех (always on top), не в панели задач; размером с пчелу, и программа двигает это окно.
- **Windows 10**: координаты и Z-порядок окон через WinAPI (ctypes: `EnumWindows`,
  `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`, пропускать свёрнутые/cloaked/tool-окна
  и свой pid). Учесть DPI-масштабирование при переводе в координаты Qt.
- **KDE Wayland**: приложение не видит чужие окна и не может само себя позиционировать. Обход:
  - запускать пчелу через XWayland (`QT_QPA_PLATFORM=xcb`), тогда она может двигать своё окно;
  - координаты окон получать из **скрипта KWin** (Plasma 6 API: `workspace.stackingOrder`,
    `frameGeometry`, `minimized`, `desktops`, сигналы `windowAdded/Removed`,
    `frameGeometryChanged`), который шлёт список окон пчеле через `callDBus`;
  - пчела регистрирует D-Bus сервис (QtDBus) и загружает скрипт через
    `org.kde.KWin /Scripting loadScript` + `run`;
  - масштаб XWayland ↔ логические координаты KWin откалибровать по собственному окну пчелы.
- Если координаты окон недоступны, садится на края экрана и панель задач.

### Идеи для поведения и характера

- Периодически взлетает, летит к случайному видимому окну, садится на верхний край.
  Если окно двигают, сворачивают, закрывают или перекрывают, возмущённо взлетает.
  Медленно двигаемое окно — может прокатиться.
- Может любить одни окна (браузер) и избегать других (терминал с ошибками), по заголовку.
- Кружит, жужжит, засыпает с «zzz», если её долго не трогать. Ночью летает реже.
- Можно поймать мышкой и перенести (смешно барахтается).
- Клик — пузырь-чат: ответы от BeeLLM, без сервера — заготовленные «бзз».
  Правое меню: дать цветок, погладить, шлёпнуть, извиниться, отпустить погулять, выход.
- Настроение по таблице выше (логика локальная, детерминированная), видно по пчеле:
  сердечки, злые искры, слёзы, вопросики. Злая летает рвано, не садится, при сильной злости
  кидается к курсору «жалить».
- Иногда сама бубнит в маленьком пузыре: «бзз», «уютное окошко», «где цветы?».

### Самая смешная идея: связка с агентами

Когда агент в Claude Code вызывает `talk_to_bee`, MCP-сервер стучится к живой пчеле
на рабочем столе. Она подлетает к окну терминала и показывает в пузыре, что сказал агент
и что ответила. Шлёпнул её агент — злится и на пользователя, пока агент не извинится.

### Ещё не решено

- Внешний вид: программная векторная пчела (легко анимировать) или пиксельные спрайты.
- Насколько назойлива: перелетает раз в пару минут или почти всё время сидит.
- Говорит ли сама через BeeLLM или живёт на заготовках, а модель — только для чата по клику.
- Что интереснее пользователю: сама пчела на экране или связь с агентами.
