# 🐝 bee-pet

Шуточный питомец для рабочего стола: пчела живёт поверх окон, у неё есть настроение,
с ней можно поболтать. Отвечает модель [BeeLLM](https://huggingface.co/schizophyllume/BeeLLM)
(~10 тысяч параметров, llama-server), а без сервера пчела говорит заготовками.

История идеи и все наработки по поведению описаны в `BEE_HANDOFF.md`.

## Файлы

- `docs/bee_mcp.py` — MCP-сервер с инструментом `talk_to_bee` для агентов Claude Code.
  Шлёт реплику в llama-server (`BEE_URL`, по умолчанию `http://127.0.0.1:8081`).
- `docs/bee_instructions.md` — фрагмент CLAUDE.md, который объясняет агентам, как общаться с пчелой.
- `bee_pet/` — код питомца (пакет, запуск `python -m bee_pet`).
- `tests/` — pytest-тесты.
- `docs/spec/` — поэтапное ТЗ на английском для субагентов (`00-common.md` + `stage-N.md`).

## Текущий этап: MVP для Windows 11

Сначала Windows. Пользователь тестирует на ноутбуке с дуалбутом Windows 11, разработка
частично идёт в Fedora KDE. Поэтому MVP не должен зависеть от платформы: в нём нет
WinAPI и KWin, он только двигает собственное окно.

Что входит в MVP:
1. **Окно-пчела**: PySide6, прозрачное, без рамки, всегда поверх остальных, без значка
   в панели задач (`Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.Tool`,
   `WA_TranslucentBackground`). Размер окна равен размеру пчелы.
2. **Перетаскивание мышкой**: пчелу можно поймать и перенести, а при переноске она барахтается.
3. **Контекстное меню** (правый клик) с командами: дать цветок, погладить, шлёпнуть,
   извиниться, побрызгать, открыть чат, выход. Каждая команда меняет настроение.
4. **Мини-чат**, который открывается из контекстного меню: маленькое окно рядом с пчелой,
   в нём поле ввода и история. Ответ приходит от BeeLLM, а если сервер недоступен,
   выбирается случайная заготовка «бзз». Запрос к модели не должен блокировать GUI
   (поток или `QThread`).
5. **Настроение** берётся из тега `[mood:level]` в ответе модели (без сервера — по
   локальной таблице ниже) и видно на пчеле значками: ❤️, 😊, искры, слёзы, «?».
6. **Злая пчела закрывает окна** (только на Windows, см. раздел ниже).
7. **Мельтешение курсором по пчеле** (быстро водить туда-сюда, без нажатия) считается
   шлепком, как команда меню; повторно не чаще раза в 3 секунды.
8. **Прогулки по окнам** (`wander.py`): спокойная пчела раз в 1–3 минуты садится на верхний
   край случайного видимого окна, а без WinAPI улетает к низу экрана. В полёте она
   жужжит в пузыре: модели уходит `*flies to another window*` без истории диалога, и
   настроение от этого не меняется.
9. **Переключение окон в простое** (только Windows): если 2 минуты нет ввода с клавиатуры
   и мыши (`GetLastInputInfo`), пчела летит к неактивному окну и выводит его на передний
   план (`AttachThreadInput` + `SetForegroundWindow`, нажатия клавиш не эмулируются).
   Перед переключением она ещё раз проверяет, что пользователь не вернулся. Окна от имени
   администратора не трогает. Выключатель «🪟 Переключать окна, пока меня нет» в меню,
   по умолчанию **включён**.

Что отложено на потом: KDE Wayland (XWayland и скрипт KWin), засыпание, ночной режим,
связка с агентами через `bee_mcp.py`.

### Внешний вид

Пчела векторная, её рисует `QPainter` в `paintEvent`: тело, полоски, машущие крылья,
значок настроения. Спрайтов нет. Анимация идёт по `QTimer` примерно с частотой 30 fps.
Масштаб экрана (DPI) учитывать через логические координаты Qt.

## Настроение

BeeLLM начинает каждый ответ с тега `[mood:level]` (neutral, happy, loving, sad, angry,
confused; level — low или high). Пчела ждёт ответа и ставит настроение из тега; angry
с уровнем high — это angry high. Если сервер недоступен или тег не разобрался, работают
локальные правила ниже (запасной путь). Жужжание в полёте настроение не меняет.

| Действие / реплика             | Настроение |
|--------------------------------|------------|
| `hi bee!`                      | neutral    |
| `*gives you a flower*`         | happy      |
| `i love you`                   | loving     |
| `*sprays you with bug spray*`  | sad        |
| `*swats you*`                  | angry      |
| `*pets you*` (погладить)       | happy      |
| непонятное (`asdfghjkl`)       | confused   |

Особое правило для злой пчелы (так же отвечает и модель): если она angry, то `sorry` переводит её в neutral, а
цветок или `i love you` злят ещё сильнее (angry high, она распознаёт лавбомбинг).
Любая провокация злой пчелы перезапускает таймеры затухания злости. Когда настроение
само затухает до neutral, история диалога с моделью сбрасывается.
Команды меню отправляют модели ровно эти реплики, а она отвечает с тем же настроением,
поэтому запасные правила без сервера ведут себя так же, как модель.

## Злая пчела закрывает окна

Срабатывает только при angry high: после шлепка пчелу задабривают цветком или «i love you»,
либо шлёпают ещё раз. Тогда пчела выбирает одно окно, подлетает к его заголовку,
«жалит» его и закрывает.

Это единственная функция, которая закрывает чужие окна (кроме неё чужих окон касается
только переключение фокуса в простое), поэтому для неё обязательны предохранители:
- **Закрывать только вежливо**: `PostMessageW(hwnd, WM_CLOSE)`. Нельзя использовать
  `TerminateProcess`, `taskkill` и прочие убийства процессов. Если в окне есть несохранённые
  данные, приложение само спросит «Сохранить?».
- **Белый список**: пчела закрывает только окна из настраиваемого списка процессов
  (`notepad.exe`, `calc.exe`, окна Проводника и т. п.), всё остальное она не трогает. Никогда
  не закрываются окна собственного процесса, системные окна (`explorer.exe` с
  рабочим столом и панелью задач, `Progman`, `Shell_TrayWnd`), окна от имени администратора,
  терминалы и IDE.
- **Предупреждение**: перед закрытием пчела несколько секунд висит у окна, в пузыре
  идёт обратный отсчёт «5…4…3…». Если за это время извиниться (`sorry` в меню или
  в чате), она успокаивается и ничего не закрывает.
- **Лимит**: закрывать не больше одного окна за приступ злости и делать паузу между приступами.
- **Выключатель**: в контекстном меню есть пункт «Разрешить кусать окна», по умолчанию
  он **включён** (так решил пользователь). Остальные предохранители всё равно действуют.

Окна перечисляются через WinAPI на `ctypes`: `EnumWindows`, `IsWindowVisible`,
`IsIconic`, `GetWindowThreadProcessId` и имя процесса (`QueryFullProcessImageNameW`).
Координаты берутся из `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`. Свёрнутые,
cloaked (`DWMWA_CLOAKED`) и tool-окна пропускаются. Физические пиксели переводятся
в логические координаты Qt с учётом DPI. На других ОС функция отключена.

## Запуск

```
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m bee_pet
.venv/bin/python -m pytest                    # GUI-тесты: QT_QPA_PLATFORM=offscreen
llama-server -hf schizophyllume/BeeLLM -c 4096 --port 8081   # необязательно, для чата
```

## Соглашения

- Python 3, PySide6. Из стандартной библиотеки для HTTP достаточно `urllib`, как в `bee_mcp.py`.
- Комментарии, docstring и тексты интерфейса на русском. Реплики для BeeLLM на английском,
  потому что модель понимает только его.
- Пока ничего не добавлять сверх описанного MVP без согласования с пользователем.
