# Проверка на Windows 11

## Установка

1. Установить Python 3.11+ с python.org (галочка «Add python.exe to PATH»).
2. В PowerShell, в папке проекта:
   ```
   py -3 -m venv .venv
   .venv\Scripts\pip install -r requirements-dev.txt
   .venv\Scripts\python -m bee_pet
   ```
3. Тесты: `.venv\Scripts\python -m pytest -q` (Qt-тесты на Windows идут без offscreen,
   при желании `$env:QT_QPA_PLATFORM="offscreen"`).
4. Чат (необязательно): `llama-server -hf schizophyllume/BeeLLM -c 4096 --port 8081`.
   Без сервера пчела отвечает заготовками.
5. Логи укуса: запускать с `$env:PYTHONUNBUFFERED=1`; для подробных причин пропуска окон
   включить уровень DEBUG для логгера `bee_pet.biting` (`logging.basicConfig(level=logging.DEBUG)`).

## Ручная проверка

### Окно и перетаскивание
- [ ] Пчела видна поверх окон, прозрачный фон, нет значка в панели задач.
- [ ] Левой кнопкой пчелу можно поймать и перенести; при переноске барахтается (ноги, быстрые крылья).
- [ ] На мониторе с масштабом 125–150 % размер и положение пчелы и пузыря нормальные.
- [ ] Пчела не выходит за пределы рабочего стола при перетаскивании.
- [ ] Перенести пчелу быстрее чем за 3 с: настроение не меняется.
- [ ] Держать пчелу 3 с: она злится (в пузыре ответ на `*grabs your wings*`), отпустить
      сразу после этого: успокаивается (ответ на `*lets you go* sorry`, neutral).
- [ ] Держать пчелу 8 с и дольше: angry high (дрожь); после отпускания остаётся в ярости.

### Метания злой пчелы
- [ ] Шлёпнуть: пчела резко прыгает с места на место недалеко от себя, с паузами.
- [ ] Довести до angry high: прыжки дальше, быстрее и почти без пауз; пчела не вылетает
      за рабочую область экрана (панель задач не перекрывает).
- [ ] Во время укуса (полёт к окну и отсчёт «5…4…3…») пчела не мечется, а висит у окна;
      после укуса снова мечется, пока злая.
- [ ] Схватить мечущуюся пчелу: прыжки прекращаются, после отпускания продолжаются.
- [ ] Злая пчела убегает от курсора: подвести мышь ближе ~150 px (angry high: ~220 px),
      пчела отскакивает в сторону от него; в углу экрана выбирается вбок, а не в угол.
- [ ] Быстрым нажатием пчелу всё равно можно схватить; с зажатой кнопкой, во время
      отсчёта укуса и при открытом меню она не уворачивается.
- [ ] Извиниться: прыжки прекращаются, прогулки по окнам возвращаются.

### Контекстное меню (правый клик)
- [ ] 🌸 Дать цветок: happy, искры, в пузыре ответ модели (без сервера — заготовка «бзз»).
- [ ] 🤚 Погладить: happy.
- [ ] 👋 Шлёпнуть: angry, красная голова, лучи.
- [ ] 🙏 Извиниться: из angry возвращает в neutral.
- [ ] 💨 Побрызгать: sad, слёзы.
- [ ] 💬 Чат: открывается рядом с пчелой.
- [ ] 🦷 Разрешить кусать окна: галочка стоит по умолчанию; состояние сохраняется после перезапуска.
- [ ] ❌ Выход закрывает приложение.

### Чат
- [ ] С запущенным llama-server: ответ приходит от модели, окно не подвисает.
- [ ] Без сервера: приходит случайная заготовка «бзз».
- [ ] С сервером: значок настроения меняется, когда приходит ответ, и совпадает с тегом
      `[mood:level]` модели (виден в логе llama-server).
- [ ] Без сервера: реплики `hi bee!`, `i love you`, `asdfghjkl`, `sorry` сразу меняют
      настроение как в таблице CLAUDE.md.

### Жужжание само по себе
- [ ] Спокойная пчела изредка (раз в 1,5–4 минуты) сама что-то жужжит в пузыре «🐝 …».
- [ ] Шлёпнуть: злая пчела ругается в пузыре каждые 6–15 с, angry high — почти непрерывно.
- [ ] От этого жужжания значок настроения не меняется (спокойная не злится, злая не остывает).
- [ ] Во время обратного отсчёта укуса в пузыре только «5…4…3…», жужжание его не затирает.
- [ ] Ответ на команду меню или чат не перебивается жужжанием, пока виден в пузыре.
- [ ] Без сервера жужжит заготовками «бзз».

### Значки настроения
- [ ] neutral (без значка), happy (искры, щёчки), loving (сердечки в глазах и вокруг),
      sad (слёзы, опущенные усики), angry (красная голова, лучи), angry high (дрожь, быстрые крылья),
      confused («?»).

### Укус окна
Подготовка: открыть Блокнот (`notepad.exe`) и Калькулятор, обычные (не от администратора).
- [ ] Шлёпнуть, затем дать цветок: пчела выбирает окно Блокнота/Калькулятора/Проводника,
      подлетает к его заголовку (примерно на 1/3 ширины слева).
- [ ] Висит над окном, в пузыре только обратный отсчёт «5…4…3…».
- [ ] После отсчёта быстрый выпад жалом, окно получает просьбу закрыться.
- [ ] Отмена: повторить, во время отсчёта нажать «Извиниться» (меню или `sorry` в чате):
      окно осталось.
- [ ] Отмена: во время отсчёта снять галочку «Разрешить кусать окна» — окно осталось.
- [ ] Схватить пчелу во время полёта или отсчёта: укус отменяется, окно осталось;
      после отпускания всё ещё разъярённая пчела снова летит кусать (если в этом приступе
      окно ещё не закрыто).
- [ ] Держать пчелу 8 с (angry high), отпустить: пчела летит кусать окно из белого списка.
- [ ] Во время отсчёта после этого `sorry` в чате всё ещё отменяет укус.
- [ ] При запуске `python -m bee_pet` в консоли видны решения: «цель: …», «не кусаю: …»
      (одна и та же причина не повторяется), «отмена укуса: …».
- [ ] Отмена: во время отсчёта закрыть или сдвинуть/свернуть окно-цель — ничего не закрывается.
- [ ] Один приступ — одно окно: ещё один цветок в том же приступе ничего не делает.
- [ ] Пауза: новый приступ сразу после укуса (меньше 5 минут) ничего не делает.
- [ ] Блокнот с несохранённым текстом: после укуса появляется «Сохранить?», данные не потеряны.
- [ ] Не трогаются: Терминал/PowerShell/cmd, IDE, браузер, рабочий стол и панель задач,
      окна, запущенные от имени администратора (запустить Блокнот «от администратора» — не трогает),
      окна самой пчелы.
- [ ] Калькулятор из Windows 11 (UWP) распознаётся как цель (процесс `calculatorapp.exe`).
- [ ] С выключенной галочкой пчела злится, но окон не касается.
- [ ] После укуса гладить или дарить цветок: пчела остаётся злой (картинка и ответы модели),
      злость затухает только через минуты после последней провокации.
